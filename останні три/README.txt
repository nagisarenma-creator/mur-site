МУР — НАВЧАЛЬНИЙ БАГАТОСТОРІНКОВИЙ САЙТ

1. Розпакуй ВЕСЬ архів: права кнопка миші → Видобути все.
2. Відкрий папку mur-site, потім index.html у браузері.
3. Не відкривай HTML прямо всередині ZIP: картинки й CSS можуть не підключитися.

СТРУКТУРА
index.html — головна сторінка
style.css — єдиний файл стилів УСІХ сторінок
images/cat.png — зображення головної
about/index.html, about/images/ — сторінка «Про нас» і її картинки
cats/index.html, cats/images/ — сторінка «Котики» і три SVG-ілюстрації
contacts/index.html, contacts/images/ — контакти та ілюстрація лапки

У головній сторінці стилі підключено як style.css.
У вкладених сторінках — ../style.css (на одну папку вище).
Усі картинки місцеві. Змінюючи назву файла, зміни й відповідний src у HTML.
Навігація, анімації та розкривні відповіді працюють без JavaScript.
Для Google Maps, Facebook і зовнішніх посилань потрібен інтернет.

ЗМІСТ
Мур — навчальний проєкт, а не офіційний сайт котокафе «Хвостики».
Мурко, Хмарка та Іскра — вигадані персонажі, не тварини на прилаштування.
Телефон, адреса й посилання на кафе збережені з наданого HTML.
Перед візитом перевір їх на сторінці закладу. Графік роботи не вигадано.

ДЛЯ РЕДАГУВАННЯ
Відкрий папку у редакторі. Змінюй текст у відповідному HTML,
а кольори, відступи, шрифти й анімацію — тільки у style.css.
Старий файл сайт.html збережи окремо як резервну копію.
